# CHU

หน้ากำหนดการประชุมสามัคคีธรรมสำหรับพี่น้องที่ใช้ภาษาไทย (ภาษาไทยล้วน)

```
index.html          หน้าแรก พาไปยังการประชุมที่ใกล้ที่สุดโดยอัตโนมัติ (อ่านจาก events.json)
events.json         รายการการประชุมทั้งหมด (โฟลเดอร์ ชื่อ วันเริ่ม วันจบ)
261030/index.html   ประชุมสามัคคีธรรมสุดสัปดาห์ที่เกซอนซิตี 30 ต.ค. – 2 พ.ย. 2026
```

## หน้าแรกเลือกอะไร

- การประชุมที่ยังไม่จบ (นับรวมวันสุดท้าย) ที่เริ่มเร็วที่สุด
- ถ้าจบหมดแล้ว จะไปที่การประชุมที่เริ่มล่าสุด

## เพิ่มการประชุมใหม่

1. สร้างโฟลเดอร์ชื่อวันเริ่มแบบ ปปเดดด เช่น `261120` แล้วใส่ `index.html` ไว้ข้างใน
2. เพิ่มหนึ่งรายการใน `events.json` (`id` ตรงกับชื่อโฟลเดอร์, `start`, `end` เป็น ปปปป-ดด-วว)

## การอัปเดตข้อมูลของหน้า 261030

หน้า `261030` อ่านข้อมูลสดจากต้นฉบับ (`event.json` ของ truman-ai/gathering-2026f-r9k2)
ทุกครั้งที่เปิดหน้า และตรวจซ้ำทุก 5 นาที ไม่ต้องแก้ไฟล์เองเมื่อต้นฉบับเปลี่ยน
หากอ่านต้นฉบับไม่ได้ หน้าจะใช้ข้อมูลสำรองที่ฝังไว้ในไฟล์ (ค่า `SNAPSHOT`) และแจ้งไว้ท้ายหน้า
